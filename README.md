# Phishing Website Detection Using Machine Learning

## Project Overview
This academic project explores the use of machine learning to identify potentially phishing websites from URL-related features.

The goal is to help distinguish suspicious URLs from legitimate ones and improve awareness of online threats.

## Objectives
- Prepare and analyze a phishing website dataset.
- Extract and process URL-related features.
- Train a Random Forest classification model.
- Evaluate the model using appropriate performance metrics.
- Test predictions on individual URLs.
